17. Deep Dive into Datetime Engine, Math Operators, and JSON Pipelines

import datetime
import math
import json

1. The Datetime Engine & String Formatting

Python relies on the built-in 'datetime' module to instantiate temporal stamps.

# Fetching the exact current machine operational runtime parameters
current_snapshot = datetime.datetime.now()
print("--- Datetime Extraction Matrix ---")
print(f"Raw Object: {current_snapshot}")
print(f"Extracted Year Factor: {current_snapshot.year}")

# --- Formatting Datetime Objects into Strings via strftime() ---
# %A -> Weekday fullname | %B -> Month fullname | %Y -> 4-digit Year
formatted_day = current_snapshot.strftime("%A")
formatted_month = current_snapshot.strftime("%B")
print(f"Human Readable Strings: {formatted_day} of {formatted_month}")

# --- Manually Instantiating Explicit Target Dates ---
# Signature: datetime.datetime(year, month, day, hour=0, minute=0, second=0)
historical_checkpoint = datetime.datetime(2020, 5, 17, 14, 30)
print(f"Configured Static Checkpoint: {historical_checkpoint}")

2. Core Mathematics & The Math Module

Python provides global primitives (min, max, abs, pow) and a specialized 'math' module.

# A) Global Built-in Functions
print("\n--- Core Mathematics Outputs ---")
print(f"Max Value Check: {max(5, 10, 25)}")
print(f"Min Value Check: {min(5, 10, 25)}")
print(f"Absolute Vector Magnitude: {abs(-7.25)}")
print(f"Power Calculation Engine (4^3): {pow(4, 3)}")

# B) Specialized math Module Operations
print(f"Square Root Calculation: {math.sqrt(64)}")
print(f"Ceiling Rounding (math.ceil 1.4): {math.ceil(1.4)}")   # Rounds UP to next integer
print(f"Floor Rounding (math.floor 1.4): {math.floor(1.4)}") # Rounds DOWN to next integer
print(f"Mathematical PI Constant Value: {math.pi}")

3. JSON Serialization & Deserialization Pipelines

Data transmission requires mapping native Python objects into compliant JSON text strings.

  • json.loads(): Parses an incoming JSON string and transforms it into a Python Dict.
  • json.dumps(): Converts a native Python collection into an outgoing JSON string format.
print("\n--- JSON Serialization Actions ---")

# A) Deserialization: JSON Text String ---> Native Python Dictionary
incoming_json_payload = '{"name": "John", "age": 30, "city": "New York"}'
parsed_python_dict = json.loads(incoming_json_payload)
print(f"Deserialized Dict Lookup: {parsed_python_dict['city']} | Type: {type(parsed_python_dict)}")

# B) Serialization: Native Python Object ---> Outgoing JSON Text String
developer_profile = {
    "username": "kubra_dev",
    "verified": True,
    "credentials": None,
    "active_repositories": ["engine_v1", "ui_v2"]
}

# Converting into a raw, single-line unformatted string payload
raw_json_output = json.dumps(developer_profile)
print(f"Raw Serialized String: {raw_json_output}")

# --- Advanced Pretty Printing & Sorting Arguments ---
# - indent: Formats with structured tab indent spaces.
# - sort_keys: Forces JSON keys to be serialized alphabetically.
# - separators: Overrides default token spaces to reduce data overhead padding.
optimized_json_output = json.dumps(
    developer_profile, 
    indent=4, 
    sort_keys=True, 
    separators=(",", ": ")
)
print("\n--- Optimized Visual JSON Printout ---")
print(optimized_json_output)
