1. Hash Tables & Collision Resolution via Chaining

Academic Overview:

  • Objective: To achieve optimal lookups, insertions, and deletions in $O(1)$ average time complexity.
  • Hash Function: Maps an arbitrary key (e.g., "Bob") to a fixed index within the underlying array.
  • Collision: Occurs when two distinct keys yield the exact same index (e.g., "Lisa" and "Stuart" mapping to index 3).
  • Chaining Strategy: Resolves collisions by converting every index (bucket) into a separate linked sub-list. Colliding elements are simply appended to that sub-list chain.
print("--- 1. Custom Hash Table via Collision Chaining Mechanism ---")

class HashTable:
    def __init__(self, size=10):
        self.size = size
        # Initializing a list of empty list buckets
        self.table = [[] for _ in range(self.size)]

    def _hash_function(self, key):
        """Summates the Unicode code points of characters and applies modulo operations."""
        return sum(ord(char) for char in key) % self.size

    def add(self, key):
        """Inserts a key into the corresponding bucket. Handles collisions seamlessly."""
        index = self._hash_function(key)
        if key not in self.table[index]:
            self.table[index].append(key)  # Appends to the chain if it doesn't exist

    def contains(self, key):
        """Checks for the presence of a key within the localized bucket chain."""
        index = self._hash_function(key)
        return key in self.table[index]

# Hash Table Demonstration
hash_map = HashTable()
dataset = ['Bob', 'Pete', 'Jones', 'Lisa', 'Siri', 'Stuart']
for name in dataset:
    hash_map.add(name)

print(f"Internal Hash Table State: {hash_map.table}")
print(f"Is 'Pete' registered in Hash Table?: {hash_map.contains('Pete')}")

2. Binary Trees & Depth-First Search (DFS) Traversals

Academic Overview:

  • Binary Tree: A non-linear hierarchical structure where each node has at most two children (designated as Left and Right nodes).
  • DFS Traversals: Explores tree branches deeply down a vertical axis before shifting horizontally.
    • Pre-Order ($\text{Root} \rightarrow \text{Left} \rightarrow \text{Right}$): Ideal for cloning or duplicating structural tree paths.
    • In-Order ($\text{Left} \rightarrow \text{Root} \rightarrow \text{Right}$): Natively retrieves sorted values in non-decreasing order from a Binary Search Tree (BST).
    • Post-Order ($\text{Left} \rightarrow \text{Right} \rightarrow \text{Root}$): Highly optimized for clearing or deleting subtrees and parsing mathematical postfix expressions.
print("\n--- 2. Hierarchical Binary Tree and DFS Recursive Traversals ---")

class TreeNode:
    def __init__(self, data):
        self.data = data
        self.left = None
        self.right = None

# Recursive Traversal Algorithms
def pre_order_traversal(node):
    if node:
        print(node.data, end=", ")
        pre_order_traversal(node.left)
        pre_order_traversal(node.right)

def in_order_traversal(node):
    if node:
        in_order_traversal(node.left)
        print(node.data, end=", ")
        in_order_traversal(node.right)

def post_order_traversal(node):
    if node:
        post_order_traversal(node.left)
        post_order_traversal(node.right)
        print(node.data, end=", ")

# Tree Construction (Root: R, Children: A and B)
tree_root = TreeNode('R')
tree_root.left = TreeNode('A')
tree_root.right = TreeNode('B')
tree_root.left.left = TreeNode('C')
tree_root.left.right = TreeNode('D')

print("DFS Pre-Order   (Root -> L -> R): ", end=""); pre_order_traversal(tree_root); print()
print("DFS In-Order    (L -> Root -> R): ", end=""); in_order_traversal(tree_root); print()
print("DFS Post-Order  (L -> R -> Root): ", end=""); post_order_traversal(tree_root); print()

3. Self-Balancing AVL Trees

Academic Overview:

  • Objective: Standard Binary Search Trees (BST) can degenerate into highly skewed linear chains costing $O(n)$ time operations. AVL trees actively enforce rigid height balance conditions to guarantee strict $O(\log n)$ efficiency bounds.
  • Balance Factor ($\text{BF}$): The absolute calculated height difference between the left and right subtrees must strictly satisfy: $$\text{BF} = \text{height}(\text{left}) - \text{height}(\text{right}) \in \{-1, 0, 1\}$$
  • Rotations: Triggered programmatically during insertion or deletion workflows to neutralize node imbalances ($\text{Left-Left (LL)}$, $\text{Right-Right (RR)}$, $\text{Left-Right (LR)}$, $\text{Right-Left (RL)}$ cases).
print("\n--- 3. Self-Balancing AVL Tree Rotational Mechanics ---")

class AVLTreeNode:
    def __init__(self, data):
        self.data = data
        self.left = None
        self.right = None
        self.height = 1

def get_node_height(node):
    return node.height if node else 0

def calculate_balance_factor(node):
    return get_node_height(node.left) - get_node_height(node.right) if node else 0

def execute_right_rotation(y):
    print(f"[ROTATION] Initiating Single Right Rotation on Node: {y.data}")
    x = y.left
    T2 = x.right
    # Re-linking nodes to restore balance
    x.right = y
    y.left = T2
    # Recalculating heights post-rotation
    y.height = 1 + max(get_node_height(y.left), get_node_height(y.right))
    x.height = 1 + max(get_node_height(x.left), get_node_height(x.right))
    return x

def execute_left_rotation(x):
    print(f"[ROTATION] Initiating Single Left Rotation on Node: {x.data}")
    y = x.right
    T2 = y.left
    # Re-linking nodes to restore balance
    y.left = x
    x.right = T2
    # Recalculating heights post-rotation
    x.height = 1 + max(get_node_height(x.left), get_node_height(x.right))
    y.height = 1 + max(get_node_height(y.left), get_node_height(y.right))
    return y

def insert_into_avl(node, data):
    """Recursively inserts data and balances the tree on the way back up (Backtracking)."""
    if not node:
        return AVLTreeNode(data)
    
    if data < node.data:
        node.left = insert_into_avl(node.left, data)
    else:
        node.right = insert_into_avl(node.right, data)

    # Height and structural validation updates
    node.height = 1 + max(get_node_height(node.left), get_node_height(node.right))
    balance_factor = calculate_balance_factor(node)

    # Case 1: Left-Left (LL) Deviation -> Requires a Single Right Rotation
    if balance_factor > 1 and data < node.left.data:
        return execute_right_rotation(node)

    # Case 2: Right-Right (RR) Deviation -> Requires a Single Left Rotation
    if balance_factor < -1 and data > node.right.data:
        return execute_left_rotation(node)

    return node

# AVL Stabilization Demo
avl_root = None
alphabetical_nodes = ['A', 'B', 'C'] # Consecutive additions that enforce an RR rotation
for char in alphabetical_nodes:
    avl_root = insert_into_avl(avl_root, char)

4. Graphs & Adjacency Matrix vs List Coupling

Academic Overview:

  • Concept: A non-linear architectural grid composed of Vertices (nodes) intersected via tracking Edges (connections linking vertices).
  • Classifications: Can be explicitly configured as Directed (one-way edge paths) or Undirected (bidirectional relationships).
  • Representation: Most optimally modeled in Python via an Adjacency List mapped utilizing dictionaries. This design provides structural $O(V + E)$ space complexity efficiency compared to memory-heavy $O(V^2)$ sequential Adjacency Matrix configurations.
print("\n--- 4. Graph Network Map Representation via Adjacency Lists ---")

class Graph:
    def __init__(self):
        self.adjacency_list = {}  # Using dictionary map to link nodes and list relationships

    def add_vertex(self, vertex):
        """Registers a unique vertex point into the network system."""
        if vertex not in self.adjacency_list:
            self.adjacency_list[vertex] = []

    def add_edge(self, vertex1, vertex2):
        """Constructs a mutual, undirected edge bridge between two target vertices."""
        if vertex1 in self.adjacency_list and vertex2 in self.adjacency_list:
            self.adjacency_list[vertex1].append(vertex2)
            self.adjacency_list[vertex2].append(vertex1)  # Ensures bidirectional coupling

# Network Topology Simulation
social_network = Graph()
users = ["Kubra", "Ahmet", "Mehmet"]
for user in users:
    social_network.add_vertex(user)

# Linking network nodes
social_network.add_edge("Kubra", "Ahmet")
social_network.add_edge("Ahmet", "Mehmet")

print(f"Network Connection Mapping: {social_network.adjacency_list}")
