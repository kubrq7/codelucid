06. Deep Dive into Python Booleans (True/False), Truthy & Falsy Values

1. What is a Boolean?

Booleans represent one of two values: True or False. When you compare two values, Python evaluates the expression and returns a Boolean answer.

print(10 > 9)  # Output: True
print(10 == 9) # Output: False

2. The bool() Function & Truthy Values

The bool() function allows you to evaluate any value. Most values are "Truthy" (they have content).

print(bool("Hello")) # True
print(bool(15))      # True

3. Falsy Values (The Empty & Zero Rule)

If it is empty, zero, or absent, it is FALSE!

print(bool(False)) # False
print(bool(None))  # False
print(bool(0))     # False
print(bool(""))    # False
print(bool(()))    # False
print(bool([]))    # False
print(bool({}))    # False
⚠️ ADVANCED OBJECT TRICK (__len__): If an object is created from a class that has a __len__ function that returns 0 or False, that object also evaluates to False!

4. Functions Returning Booleans

You can create custom functions that return a Boolean value using the 'return' keyword.

def my_function():
    return True

if my_function():
    print("YES!")

5. Built-in Boolean Functions: isinstance()

The isinstance() function checks if an object belongs to a specific data type.

x = 200
print(isinstance(x, int)) # Output: True
