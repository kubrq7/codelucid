03. Advanced Machine Learning Models: Regression, Scaling, and Classification

A comprehensive technical exploration of predictive modeling systems utilizing scikit-learn, scipy, and pandas.

import numpy as np
from scipy import stats
import pandas as pd
from sklearn import linear_model
from sklearn.preprocessing import StandardScaler
from sklearn import tree
import matplotlib.pyplot as plt

1. Linear Regression & Future Predictions

Linear regression handles tracking correlations and fitting an optimized trendline across numeric variables. The predictive architecture maps relationships via the classical line equation:

$$y = mx + c$$ 
print("--- 1. Executive Linear Regression Training & R-Correlation ---")

# Data: Car Age (x) vs Registered Max Speed (y)
car_age = [5, 7, 8, 7, 2, 17, 2, 9, 4, 11, 12, 9, 6]
car_speed = [99, 86, 87, 88, 111, 86, 103, 87, 94, 78, 77, 85, 86]

# linregress calculates the slope, intercept, and the critical r-correlation coefficient
slope, intercept, r_value, p_value, std_err = stats.linregress(car_age, car_speed)

# Naming correlation validity: r ranges from -1 to 1. 0 means no relationship.
print(f"R-Correlation Coefficient: {r_value:.4f}") # Approx -0.76 indicates strong negative correlation

# Prediction function using the mathematical line equation
def predict_speed_by_age(age):
    return slope * age + intercept

# Predicting a 10-year old vehicle speed threshold
predicted_speed_10 = predict_speed_by_age(10)
print(f"Predicted speed of a 10-year-old vehicle: {predicted_speed_10:.2f} km/h")

# Visualizing regression line mapping over scatter points
plt.figure(figsize=(6, 4))
plt.scatter(car_age, car_speed, color="blue", label="Original Data")
regression_line_model = list(map(predict_speed_by_age, car_age))
plt.plot(car_age, regression_line_model, color="red", linewidth=2, label="Regression Line")
plt.legend()
plt.title("Age vs Speed Linear Regression")
plt.savefig("07_linear_regression.png", dpi=300)
plt.close()

2. Multiple Regression Analysis

Multiple regression establishes structural predictive lines when a target variable depends on more than one independent feature framework.

print("\n--- 2. Executing Multiple Regression Models ---")

# Simulating data.csv internal structure for standalone execution safety
car_dataframe = pd.DataFrame({
    'Weight': [790, 1160, 929, 865, 1140, 929, 1109, 1365, 1112, 1150, 980, 990],
    'Volume': [1000, 1200, 1000, 900, 1500, 1000, 1400, 1500, 1500, 1600, 1100, 1300],
    'CO2': [99, 95, 95, 90, 105, 105, 90, 92, 98, 99, 99, 101]
})

# Splitting independent input features (X) from the dependent target column (y)
X_features = car_dataframe[['Weight', 'Volume']]
y_target = car_dataframe['CO2']

# Instantiating the LinearRegression object engine from Sklearn
multiple_regr_model = linear_model.LinearRegression()
multiple_regr_model.fit(X_features, y_target)

# Coefficients tell us how changing one feature affects the target
print(f"Feature Coefficients [Weight, Volume]: {multiple_regr_model.coef_}")

# Predicting CO2 metrics for a vehicle weighting 2300kg with an engine volume of 1300cm3
predicted_co2 = multiple_regr_model.predict([[2300, 1300]])
print(f"Predicted CO2 Emission Metrics: {predicted_co2[0]:.4f} g/km")

3. Data Scaling, Train/Test Validation, & Decision Trees

A) Data Scaling

When dataset features encompass drastically unaligned scales (e.g., Weights averaging 1500 against Volumes averaging 1.2), gradient-descent algorithms struggle to optimize parameters. The StandardScaler structural infrastructure normalizes features to a uniform distribution where mean $\mu = 0$ and standard deviation $\sigma = 1$.

B) Train/Test Split Methodology

To explicitly counter model overfitting risks, production validation sets partition data. Training subsets (e.g., 80%) educate predictive engines, while completely separate testing layers (e.g., 20%) act as unseen test telemetry pools to grade operational generalization performance.

C) Decision Trees & Confusion Matrices

Decision tree models dynamically route input observations down localized conditional feature branch questions until reaching localized logical classification leaves. Performance optimization checks are routinely plotted via tabular Confusion Matrices, sorting predictions across True Positives versus False Negatives grids.
