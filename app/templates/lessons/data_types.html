03. Comprehensive Map of Built-in Data Types in Python

1. The Python Data Type Map

Python has several built-in data types grouped into specific categories. You can check the data type of any object by passing it into the type() function.

1. Text Type:     str
2. Numeric Types: int, float, complex
3. Sequence Types:list, tuple, range
4. Mapping Type:  dict
5. Set Types:     set, frozenset
6. Boolean Type:  bool
7. Binary Types:  bytes, bytearray, memoryview
8. None Type:     NoneType

Quick verification example:

x = 2
print(type(x))  # Output: <class 'int'>

2. Detailed Category Examples

Category A: Text & Numeric Types

Fundamental types for storing words, whole numbers, decimals, and imaginary coordinates.

string_data = "Hello World"  # str: Textual data enclosed in quotes
integer_data = 20            # int: Whole numbers without decimals
float_data = 20.5            # float: Numbers containing decimal points
complex_data = 1j            # complex: Written with a "j" as the imaginary part

Category B: Sequence Types

Used to store multiple values in an ordered format.

my_list = ["apple", "banana", "cherry"]   # list: Mutable (changeable) and ordered collection
my_tuple = ("apple", "banana", "cherry")  # tuple: Immutable (unchangeable) and ordered collection
my_range = range(6)                       # range: Generates a fixed sequence of numbers

Category C: Mapping & Set Types

Used to store collections of unique items or key-value structures.

my_dict = {"name": "John", "age": 36}              # dict: Changeable key-value pairs
my_set = {"apple", "banana", "cherry"}             # set: Unordered, unindexed, unique items
my_frozenset = frozenset({"apple", "banana"})      # frozenset: An unchangeable (immutable) version of a set

Category D: Boolean & Special Types

Used for condition logic handling and representing empty states.

is_active = True       # bool: Represents logical state: True or False
empty_value = None      # NoneType: A special constant representing the absence of a value

Category E: Binary Types

Used to manipulate raw binary data/bytes of information.

binary_bytes = b"Hello"                # bytes: Immutable sequence of bytes
binary_array = bytearray(5)             # bytearray: Mutable sequence of bytes
binary_view = memoryview(bytes(5))      # memoryview: Directly accesses internal object buffers
