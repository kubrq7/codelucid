16. Unified Master Guide to Python Iterators and Module Architecture

1. The Iterator Protocol (__iter__ & __next__)

  • Iterable: An object that can return an iterator using the iter() method (e.g., lists, strings).
  • Iterator: A stateful object that produces values sequentially when next() is called.

Under the hood, for-loops call iter() and handle StopIteration automatically.

fruits_tuple = ("apple", "banana", "cherry")
iterator_obj = iter(fruits_tuple)

print(next(iterator_obj))  # Outputs: apple
print(next(iterator_obj))  # Outputs: banana
print(next(iterator_obj))  # Outputs: cherry
# next(iterator_obj)       # -> Triggers StopIteration Exception at runtime

# Strings are also built-in iterables
word_iterator = iter("code")
print(next(word_iterator))  # Outputs: c

2. Custom Iterators (Class Implementation)

To create an iterator object from scratch, a class must define:

  • __iter__(): Initializes state and returns the iterator object itself (self).
  • __next__(): Computes the next element, tracks index updates, and raises StopIteration to signal the collection boundary limit.
class FiniteCounter:
    """Generates sequential numbers up to a specified maximum ceiling."""
    def __init__(self, max_limit):
        self.max_limit = max_limit

    def __iter__(self):
        self.current_value = 1
        return self

    def __next__(self):
        if self.current_value <= self.max_limit:
            output = self.current_value
            self.current_value += 1
            return output
        else:
            raise StopIteration

# Consuming the custom iterator via clean loop interaction
counter_pipeline = FiniteCounter(max_limit=3)
for num in counter_pipeline:
    print(f"Custom Iterator Output: {num}")

3. Python Module Architecture & Import Mechanics

Modules allow engineers to break massive codebases into separate reusable .py files. Let's mock a module environment and check built-in platform utilities.

import platform

# Accessing platform diagnostic variables
os_type = platform.system()
print(f"\nHost Operating System: {os_type}")

# --- Introspection via dir() ---
# The dir() built-in function extracts all structural names and variables inside a module.
platform_attributes = dir(platform)
print(f"Sample of internal methods in platform module: {platform_attributes[:5]}")
