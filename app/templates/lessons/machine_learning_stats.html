02. Machine Learning Foundation: Data Types, Core Statistics, Percentiles, and Data Distributions

import numpy as np
from scipy import stats
import matplotlib.pyplot as plt

1. Comprehensive Data Types Theory

In Machine Learning, recognizing the underlying data type determines the algorithm.

  • Numerical: Numbers. Subdivided into:
    • Discrete: Countable integers limited to whole numbers (e.g., number of cars).
    • Continuous: Measured numbers that can take any decimal value (e.g., price, weight).
  • Categorical: Values containing un-comparable distinct labels (e.g., colors, Yes/No).
  • Ordinal: Categorical data that carries a meaningful order or rank (e.g., school grades A > B).

2. The Core Three Metrics (Mean, Median, Mode)

print("--- 1. Computing Central Tendency Metrics ---")
# Simulated dataset: Speed registers of 13 unique vehicles
speed_dataset = [99, 86, 87, 88, 111, 86, 103, 87, 94, 78, 77, 85, 86]

# Arithmetic Mean: Sum of all records divided by total number of records
ml_mean = np.mean(speed_dataset)
print(f"Calculated Mean Speed: {ml_mean:.2f}")

# Median: The exact middle value after sorting the array data structure
ml_median = np.median(speed_dataset)
print(f"Calculated Median Speed: {ml_median}")

# Mode: The most frequent/common value appearing inside the dataset
# stats.mode returns an object containing the mode array and count array
ml_mode = stats.mode(speed_dataset, keepdims=True)
print(f"Calculated Mode Speed: {ml_mode.mode[0]} (Appears {ml_mode.count[0]} times)")

3. Dispersion Measurements (Standard Deviation & Variance)

print("\n--- 2. Computing Variance and Standard Deviation (Dispersion) ---")
# Dataset A: Low spread (numbers close together)
low_spread_cars = [86, 87, 88, 86, 87, 85, 86]
# Dataset B: High spread (numbers widely distributed)
high_spread_cars = [32, 111, 138, 28, 59, 77, 97]

# Variance (sigma^2): Average of the squared differences from the Mean
variance_b = np.var(high_spread_cars)

# Standard Deviation (sigma): Square root of Variance. Describes how spread out numbers are.
std_dev_a = np.std(low_spread_cars)
std_dev_b = np.std(high_spread_cars)

print(f"Dataset A Standard Deviation (Low Spread): {std_dev_a:.2f}")
print(f"Dataset B Standard Deviation (High Spread): {std_dev_b:.2f}")
print(f"Dataset B Mathematically Proven Variance: {variance_b:.2f}")

4. Percentiles & Synthetic Data Distributions

print("\n--- 3. Extracting Percentiles & Creating Synthetic Distributions ---")
neighborhood_ages = [5, 31, 43, 48, 50, 41, 7, 11, 15, 39, 80, 82, 32, 2, 8, 6, 25, 36, 27, 61, 31]

# 75th Percentile: Value under which 75% of the data points fall
p75 = np.percentile(neighborhood_ages, 75)
p90 = np.percentile(neighborhood_ages, 90)
print(f"75% of people are younger than: {p75} years old.")
print(f"90% of people are younger than: {p90} years old.")

# --- Generating Big Data Visual Distributions using Matplotlib ---
print("[PROCESSING] Generating Distribution Canvas Graphics...")

# Uniform Distribution: Every value between 0.0 and 5.0 has an equal chance of selection
uniform_big_data = np.random.uniform(0.0, 5.0, 100000)

plt.figure(figsize=(6, 4))
plt.hist(uniform_big_data, 100, color="#34495e", edgecolor="white")
plt.title("Uniform Big Data Distribution Histogram")
plt.savefig("05_uniform_distribution.png", dpi=300)
plt.close()

# Normal (Gaussian) Distribution: Values cluster around a center mean value (Bell Curve)
# Params: normal(mean, standard_deviation, sample_size)
normal_big_data = np.random.normal(5.0, 1.0, 100000)

plt.figure(figsize=(6, 4))
plt.hist(normal_big_data, 100, color="#e74c3c", edgecolor="white")
plt.title("Normal (Gaussian) Distribution Bell Curve")
plt.savefig("06_normal_distribution.png", dpi=300)
plt.close()

print("[SUCCESS] Distribution images successfully saved to disk.")
