07. Ultimate Guide to Python Operators, Precedence, and Shortcuts

1. Arithmetic Operators & The Division Duo

x / y   # Standard Division (float)
x // y  # Floor Division (round down)
x % y   # Modulus (remainder)
x ** y  # Exponentiation

2. Assignment Operators & Special Structures

Shortcuts: +=, -=, *=, //=.

🚀 WALRUS OPERATOR (:=): Assigns a value within an expression. if (count := len(numbers)) > 3:

⚡ TERNARY OPERATOR: value_if_true if condition else value_if_false

3. Comparison Operators & Chaining

Python allows natural chaining: 1 < val < 10

4. Logical Operators

and, or, not.

5. Identity (is vs ==) & Membership (in)

== checks equality of value, is checks memory address identity.

6. Bitwise Operators

Operates on binary digits: &, |, ^, ~, <<, >>.

7. Operator Precedence

Order of execution: Parentheses () first, then Exponents **, followed by Multiplication/Division, and lastly Logical OR.
