02. Code Execution Order, Variables, Data Types & Global/Local Scope

1. Code Execution Order (How Python Reads)

Python programs contain multiple statements/lines. Python executes these statements one by one, from TOP to BOTTOM, in the exact order they are written.

print("Hello World!")            # 1st statement: Executed first
print("Have a good day.")        # 2nd statement: Executed second
print("Learning Python is fun!") # 3rd statement: Executed third

2. Creating Variables & Dynamic Typing

A variable is created the moment you assign a value to it for the first time using (=).

x = 5
y = "Max"
print(x)
print(y)

Dynamic Typing: Python variables do not need to be declared with a specific type. Their data types can change even after they have been defined. The latest value wins!

x = 4        # x is of type int
x = "Sally"  # x is now overwritten and becomes a type of str

3. Type Casting & The type() Function

A) Type Casting: Specifying or changing data types explicitly.

x = str(3)    # x will be '3'
y = int(3)    # y will be 3
z = float(3)  # z will be 3.0

B) The type() Function: Tells you exactly what data type a variable holds.

print(type(5))   # Output: <class 'int'>
print(type("Max")) # Output: <class 'str'>

4. Variable Names are Case-Sensitive

'a' and 'A' are completely different variables. Capital letters will NOT overwrite lowercase variables.

5. Multiple Assignments & Unpacking

# A) Many Values to Multiple Variables
x, y, z = "Apple", "Banana", "Cherry"

# B) One Value to Multiple Variables
x = y = z = "strawberry"

# C) Unpacking a Collection
fruits = ["apple", "banana", "cherry"]
x, y, z = fruits

6. Global vs Local Variables (Scope)

Variables created OUTSIDE a function are GLOBAL. Variables created INSIDE a function are LOCAL (they only live inside that block).

Trick Zone: To understand which variable Python will use, always check whether the 'print' command is indented (inside) or not indented (outside) the function.

7. Advanced Outputs with print()

Commas (,): Automatically adds a space. Best for combining different types.

Plus (+): Glues strings together without spaces. Warning: Trying to add a string and a number with '+' will crash Python (TypeError)!
