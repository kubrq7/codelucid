02. Comprehensive Master Guide to Python's Standard Libraries: Math, Random, and Statistics

import math
import random
import statistics

1. The 'math' Module (Advanced Mathematics)

The math module provides access to the mathematical functions defined by the C standard.

⚠️ NOTE: These functions do not work with complex numbers (use cmath for complex numbers).

A) Mathematical Constants & Precise Rounding

# Essential mathematical constants
print(f"Archimedes' Constant (Pi): {math.pi}")
print(f"Euler's Number (e): {math.e}")

# Precise rounding engines
value = 4.23
print(f"Absolute Ceiling (math.ceil): {math.ceil(value)}")    # Rounds UP to next integer -> 5
print(f"Absolute Floor (math.floor): {math.floor(value)}")    # Rounds DOWN to next integer -> 4

B) Power, Logarithms, and Roots

# Square Root calculation
print(f"Square Root of 144: {math.sqrt(144)}")

# Absolute value (removes negative signs, always returns float)
print(f"Absolute Value of -7.5: {math.fabs(-7.5)}")

# Power function (x raised to power y)
print(f"Power (2^3): {math.pow(2, 3)}")

# Logarithmic operations
print(f"Natural Logarithm of 10: {math.log(10)}")
print(f"Logarithm Base 10 of 100: {math.log10(100)}")

2. The 'random' Module (Pseudo-Random Generation)

❌ SECURITY WARNING: This module uses pseudo-random algorithms. Do not use it for security or cryptography! For security tokens or passwords, use the built-in secrets module.

A) Numerical Random Generation

# random() generates a float between 0.0 and 1.0 (exclusive)
print(f"Random Float [0.0 - 1.0): {random.random()}")

# uniform(a, b) generates a float between a and b (inclusive)
print(f"Random Uniform Float [5.0 - 10.0]: {random.uniform(5.0, 10.0)}")

# randint(a, b) generates an integer between a and b (inclusive)
print(f"Random Integer [1 - 100]: {random.randint(1, 100)}")

# randrange(start, stop, step) generates a random item from a specified range
print(f"Random Even Integer from Range [0, 2, 4, ... 10]: {random.randrange(0, 11, 2)}")

B) Sequence Manipulation (Choices & Shuffling)

items_list = ["Apple", "Banana", "Cherry", "Date", "Elderberry"]

# choice(sequence) picks a single random element
print(f"Single Random Choice: {random.choice(items_list)}")

# sample(sequence, k) picks k unique elements without changing the original list
print(f"Random Sample (3 Unique Items): {random.sample(items_list, k=3)}")

# shuffle(sequence) reorders the original list IN-PLACE (mutates the list)
random.shuffle(items_list)
print(f"Mutated List After Shuffle: {items_list}")

3. The 'statistics' Module (Basic Data Analysis)

Perfect for quick mathematical data analysis without importing heavy frameworks.

A) Statistical Central Tendency Metrics

dataset = [10, 20, 20, 35, 40, 50, 90]

# mean() calculates the arithmetic average
print(f"Dataset: {dataset}")
print(f"Arithmetic Mean (Average): {statistics.mean(dataset)}")

# median() finds the exact middle value of the dataset
print(f"Median (Middle Value): {statistics.median(dataset)}")

# mode() finds the most common/frequent value in the data
print(f"Mode (Most Frequent Value): {statistics.mode(dataset)}")

# stdev() calculates the standard deviation (measure of data dispersion)
print(f"Standard Deviation: {statistics.stdev(dataset):.4f}")
