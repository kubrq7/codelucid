01. Comprehensive Master Guide to Data Visualization with Matplotlib

Covering Line, Bar, Scatter Plots, and Customizations.

⚠️ NOTE FOR STUDENTS: Before running this script, you must install matplotlib via pip:
pip install matplotlib 
import matplotlib.pyplot as plt

1. The Foundational Line Plot (Basic Customization)

Line plots are ideal for tracking changes over periods of time.

print("--- 1. Generating Custom Line Plot Infrastructure ---")

# Mock data: Months and simulated software project deployment counts
months = ["Jan", "Feb", "Mar", "Apr", "May", "Jun"]
deployments = [5, 12, 18, 15, 28, 35]

# Creating a canvas figure with specific dimension sizes (Width, Height in inches)
plt.figure(figsize=(8, 5))

# Plotting with explicit styles: color, line style, marker points, and line width
plt.plot(months, deployments, color="#2c3e50", linestyle="--", marker="o", linewidth=2, label="Production Releases")

# Adding structural metadata labels
plt.title("System Deployment Velocity (First Half of 2026)", fontsize=14, fontweight="bold", pad=15)
plt.xlabel("Timeline (Months)", fontsize=12)
plt.ylabel("Total Deployments", fontsize=12)

# Customizing the background grid lines for precise readability
plt.grid(True, linestyle=":", alpha=0.6, color="gray")

# Displaying the plot legend box based on the 'label' parameter inside plt.plot
plt.legend(loc="upper left")

# Tight layout automatically adjusts subplot parameters to give specified padding
plt.tight_layout()

# In an interactive IDE, plt.show() renders the window canvas. 
# For this script ecosystem, we save it directly to prevent execution blocks.
plt.savefig("01_line_plot.png", dpi=300)
plt.close() # Always close the plot to clear memory buffers!
print("[SUCCESS] '01_line_plot.png' successfully generated on disk.\n")

2. Categorical Comparisons (Bar Charts)

Bar charts are perfect for comparing distinct categories against numerical values.

print("--- 2. Generating Categorical Bar Chart Foundations ---")

languages = ["Python", "JavaScript", "C++", "Java", "Go"]
popularity_score = [95, 88, 62, 70, 55]

plt.figure(figsize=(8, 5))

# Generating vertical bars with custom Hex hexadecimal color mapping themes
bar_colors = ["#3498db", "#f1c40f", "#e74c3c", "#f39c12", "#1abc9c"]
plt.bar(languages, popularity_score, color=bar_colors, edgecolor="black", alpha=0.85)

plt.title("Backend Ecosystem Dominance Index", fontsize=14, fontweight="bold", pad=15)
plt.xlabel("Programming Languages", fontsize=12)
plt.ylabel("Popularity Percentage (%)", fontsize=12)
plt.ylim(0, 100) # Setting explicit vertical limits for scaling calibration

plt.tight_layout()
plt.savefig("02_bar_chart.png", dpi=300)
plt.close()
print("[SUCCESS] '02_bar_chart.png' successfully generated on disk.\n")

3. Relationship Analysis (Scatter Plots)

Scatter plots are used to observe and show relationships between two numeric variables.

print("--- 3. Generating Scatter Plot Relationship Frameworks ---")

# Mock Data: Studying hours vs Exam performance scores of students
studying_hours = [2, 5, 7, 8, 10, 11, 14, 15, 17, 20]
exam_scores = [45, 52, 60, 68, 72, 80, 85, 88, 92, 98]

plt.figure(figsize=(8, 5))

# s = marker size, c = color code, marker = structural design element
plt.scatter(studying_hours, exam_scores, s=100, c="#8e44ad", marker="D", edgecolor="black", alpha=0.9, label="Student Records")

plt.title("Correlation: Study Endurance vs Academic Scores", fontsize=14, fontweight="bold", pad=15)
plt.xlabel("Total Study Time (Hours)", fontsize=12)
plt.ylabel("Final Examination Score", fontsize=12)
plt.grid(True, linestyle="-.", alpha=0.4)
plt.legend()

plt.tight_layout()
plt.savefig("03_scatter_plot.png", dpi=300)
plt.close()
print("[SUCCESS] '03_scatter_plot.png' successfully generated on disk.\n")

4. The Multi-Panel Masterpiece (Subplots)

Subplots allow you to display multiple separate graphs side-by-side in one figure window canvas.

print("--- 4. Assembling Combined Subplot Matrices ---")

# Initializing a structural subplot layout matrix grid (1 row, 2 columns)
fig, axes = plt.subplots(1, 2, figsize=(14, 6))

# --- Left Axis Plot (Index 0): Linear Trend Analytics ---
axes[0].plot([1, 2, 3, 4], [10, 20, 30, 40], color="#c0392b", marker="^", linewidth=3)
axes[0].set_title("Linear Revenue Expansion", fontsize=12, fontweight="bold")
axes[0].set_xlabel("Quarterly Intervals")
axes[0].set_ylabel("Capital Yield ($)")
axes[0].grid(True)

# --- Right Axis Plot (Index 1): Exponential Growth Curve ---
axes[1].plot([1, 2, 3, 4], [10, 40, 90, 160], color="#27ae60", marker="s", linewidth=3)
axes[1].set_title("Exponential Growth Curve", fontsize=12, fontweight="bold")
axes[1].set_xlabel("Quarterly Intervals")
axes[1].set_ylabel("User Scaling Metrics")
axes[1].grid(True)

# Setting a unified main layout header title across the entire subplot structure canvas
fig.suptitle("Executive Quarterly Performance Telemetry Matrix", fontsize=16, fontweight="bold")

plt.tight_layout()
fig.savefig("04_subplots_matrix.png", dpi=300)
plt.close()
print("[SUCCESS] '04_subplots_matrix.png' successfully generated on disk.")
