08. Master Guide to Python Lists (Creation, Manipulation, Comprehension)

1. List Basics & The 4 Built-in Collections

engines = ["Cyberpunk", "Unreal", "Unity", "Godot", "Unreal"]
print(engines)      # Allows duplicates! Outputs both instances of 'Unreal'
print(type(engines)) # Output: <class 'list'>
print(len(engines))  # Output: 5

mixed_profile = ["Dev_Kubra", 2026, True, 98.7]
languages = list(("Python", "HTML", "CSS"))

2. Accessing List Items & Slicing Boundaries

tools = ["VS_Code", "Git", "Docker", "Terminal", "Postman", "Figma"]

print(tools[1])   # Positive Indexing -> Output: Git
print(tools[-1])  # Negative Indexing (starts from end) -> Output: Figma

# ⚠️ THE SLICING RULES
print(tools[2:5]) # Index 2, 3, and 4 -> Output: ['Docker', 'Terminal', 'Postman']
print(tools[:3])  # From start up to index 3 -> Output: ['VS_Code', 'Git', 'Docker']
print(tools[3:])  # From index 3 to the very end -> Output: ['Terminal', 'Postman', 'Figma']
print(tools[-4:-1]) # Negative slice -> Output: ['Docker', 'Terminal', 'Postman']

3. Modifying & Inserting Items

servers = ["Apache", "Nginx", "IIS"]

game_modes = ["Survival", "Sandbox", "Creative", "Hardcore"]
game_modes[1:3] = ["StoryMode", "RPG", "Co-Op"]

4. Adding & Extending Lists

backlog = ["Fix Bug 01", "Update CSS"]
backlog.append("Deploy Server")
backlog.insert(1, "Review Code")
hardware = ["CPU", "GPU"]
peripherals = ("Mouse", "Keyboard")
hardware.extend(peripherals)
print(hardware) # Output: ['CPU', 'GPU', 'Mouse', 'Keyboard']

projects = ["Web_App", "AI_Bot", "Game_Jam", "AI_Bot", "Scripts"]

popped_item = projects.pop(2)

6. Iterating / Looping Through Lists

skills = ["Frontend", "Backend", "Databases"]
for skill in skills:
    print(f"Skill: {skill}")

for i in range(len(skills)):
    print(f"Index {i}: {skills[i]}")

[print(f"Short Loop: {item}") for item in skills]

7. List Comprehension (The Inline Magic)

scores = [45, 82, 94, 55, 70, 100]
engineered_scores = [s for s in scores if s > 60]
caps_skills = [x.upper() for x in skills]
tasks = ["Done", "WIP", "Pending", "WIP"]
updated_tasks = [t if t != "WIP" else "Testing" for t in tasks]

8. Sorting & Reversing Realities

⚠️ CRITICAL: sort() alters the ORIGINAL list directly (In-place mutation)!
⚠️ CASE-SENSITIVE SORT TRAP: sort() groups ALL Capital letters before lowercase letters! Use tags.sort(key=str.lower) for a true alphabetical sort. 
matrix_values = [88, 21, 5, 64, 12]
matrix_values.sort()
matrix_values.sort(reverse=True)
checkpoint_saves = ["Level 1", "Boss Fight", "Level 2"]
checkpoint_saves.reverse()

9. Safe Copying & Memory Referencing

Typing 'list_b = list_a' DOES NOT copy the list. It creates a reference link.

copy_method_1 = original.copy()
copy_method_2 = list(original)
copy_method_3 = original[:]
