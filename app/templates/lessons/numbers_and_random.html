04. Deep Dive into Python Numbers, Scientific Notation, Casting & Random

1. The Three Numeric Types

Python recognizes integers, floats, and complex numbers automatically upon assignment.

x = 1    # int (Integer)
y = 2.8  # float (Floating-Point Number)
z = 1j   # complex (Complex Number)

A) Deep Dive: int (Integer)

Whole numbers, positive or negative, without decimals, of unlimited length.

integer_pos = 1
integer_huge = 35656222554887711
integer_neg = -3255522

B) Deep Dive: float (Floating-Point)

Numbers containing one or more decimals, positive or negative. Floats can also be scientific numbers with an "e" or "E" to indicate the power of 10.

sci_pos = 35e3     # 35 * 10^3  -> 35000.0
sci_capital = 12E4 # 12 * 10^4  -> 120000.0
sci_huge = -87.7e100

C) Deep Dive: complex

Complex numbers are written with a "j" as the imaginary part.

comp1 = 3+5j
comp2 = 5j
comp3 = -5j

2. Type Casting Between Numbers

Convert numbers using int(), float(), and complex().

# Convert from float to int:
# WARNING: This truncates the decimal part (2.8 becomes 2)
b = int(2.8)
❌ THE COMPLEX CRASH RULE: You CANNOT convert complex numbers into another number type! Writing int(1j) or float(1j) will crash Python immediately.

3. Random Number Generation

Python includes a built-in module named 'random'.

import random

# random.randrange(start, stop)
# Generates a random number from 'start' up to (but NOT including) 'stop'.
print(random.randrange(1, 10))
