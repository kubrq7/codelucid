04. Python DSA Unit - Chapter 4: Advanced & Non-Comparison Sorting

An advanced technical deep-dive into complex logarithmic comparison-based sorts and linear non-comparison distribution sorting mechanics.

1. Quicksort (Divide-and-Conquer with In-Place Partitioning)

Academic Overview:

  • Concept: Establishes an arbitrary 'pivot' reference point, grouping all lesser values into a left sub-array and greater elements into a right sub-array before recursively applying the same system to both subsets.
  • Critical Interview Insight: Selecting the terminal element via standard Lomuto partitioning presents major design flaws. If the dataset arrives already sorted, performance drops to a severe worst-case footprint of $O(n^2)$ due to extremely uneven, highly asymmetrical partition breakdowns.
  • Complexity: Average $O(n \log n)$, Worst $O(n^2)$. Space Complexity: $O(\log n)$ recursive call stack overhead.
print("--- 1. Advanced Sorting: In-Place Quicksort (Lomuto Partition Scheme) ---")

def partition(array, low, high):
    # Standard Lomuto scheme picks the rightmost element as pivot
    pivot = array[high]
    i = low - 1  # Index of smaller element

    for j in range(low, high):
        # If current element is smaller than or equal to pivot
        if array[j] <= pivot:
            i += 1
            # In-place pointer swap avoiding high-level memory allocations
            array[i], array[j] = array[j], array[i]

    # Swap the pivot element with the greater element specified at i + 1
    array[i + 1], array[high] = array[high], array[i + 1]
    return i + 1  # Return the partitioning index

def quicksort(array, low=0, high=None):
    if high is None:
        high = len(array) - 1

    # Base case: If low index exceeds high, the sub-array is completely sorted
    if low < high:
        pivot_index = partition(array, low, high)
        
        # Recursively sort elements before partition and after partition
        quicksort(array, low, pivot_index - 1)
        quicksort(array, pivot_index + 1, high)

# Execution Demo
quicksort_target = [64, 34, 25, 5, 22, 11, 90, 12]
quicksort(quicksort_target)
print(f"[Quicksort Output] Sorted Array: {quicksort_target}")

2. Merge Sort (Recursive and Stable Divide-and-Conquer)

Academic Overview:

  • Concept: Recursively cuts arrays into individual elements before joining them back together in a structured sorted framework.
  • Advantage: Guarantees solid, predictable $O(n \log n)$ complexity boundaries across all scenarios (Best, Average, Worst).
  • Disadvantage: Merge Sort is fundamentally not an in-place engine. It relies heavily on temporary transient slices during recombination phases, resulting in an $O(n)$ auxiliary space profile.
print("\n--- 2. Stable Merge Sort (Recursive Framework) ---")

def merge_sort(arr):
    # Base case: single element arrays are implicitly sorted
    if len(arr) <= 1:
        return arr

    mid = len(arr) // 2
    left_half = arr[:mid]   # O(n) slicing allocation
    right_half = arr[mid:]  # O(n) slicing allocation

    # Recursive division of problem space
    sorted_left = merge_sort(left_half)
    sorted_right = merge_sort(right_half)

    return merge_subarrays(sorted_left, sorted_right)

def merge_subarrays(left, right):
    result = []
    i = j = 0

    # Linear comparison step - ensures stability
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:  # '<=' maintains stability of equivalent keys
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1

    # Append any leftover structural nodes from either side
    result.extend(left[i:])
    result.extend(right[j:])
    return result

# Execution Demo
merge_target = [3, 7, 6, -10, 15, 23.5, 55, -13]
print(f"[Recursive Merge Sort] Sorted Array: {merge_sort(merge_target)}")

3. Counting Sort (Non-Comparison Linear Time Algorithm)

Academic Overview:

  • Concept: Avoids comparison checks completely by tracking element occurrences inside a map of consecutive indices.
  • Strict Bottlenecks:
    • Mandates non-negative integer values to cleanly handle index addressing maps.
    • Bounded Range Threshold: If the variation span of values ($k$) wildly outgrows the overall item volume ($n$), memory footprints explode, neutralizing the performance benefits.
  • Complexity: Time Complexity of $O(n + k)$ where $n$ is data volume and $k$ represents the unique element span. Space Complexity: $O(k)$.
print("\n--- 3. Non-Comparison Counting Sort (Linear Time O(n + k)) ---")

def optimized_counting_sort(arr):
    if not arr:
        return arr
        
    max_val = max(arr)
    # Instantiate counting bucket array populated with zeros
    count_bucket = [0] * (max_val + 1)

    # Populate frequencies without modifying or destroying the source data structure size
    for num in arr:
        count_bucket[num] += 1

    # Reconstruct the array sequentially by iterating through frequencies
    write_index = 0
    for value, frequency in enumerate(count_bucket):
        while frequency > 0:
            arr[write_index] = value
            write_index += 1
            frequency -= 1

    return arr

counting_target = [4, 2, 2, 6, 3, 3, 1, 6, 5, 2, 3]
print(f"[Counting Sort Output] Sorted Array: {optimized_counting_sort(counting_target)}")

4. Radix Sort (Digit-by-Digit Structural Sorting)

Academic Overview:

  • Concept: Processes raw numbers digit-by-digit, moving from the Least Significant Digit ($\text{LSD}$) to the Most Significant Digit ($\text{MSD}$) while sorting intermediate places into sub-buckets.
  • The Stability Imperative: Radix sort completely depends on a stable underlying sort engine. If identical digits change their relative order during any intermediate run, the structural sequence falls apart.
  • Complexity: Time Complexity of $O(n \cdot d)$ where $d$ indicates the length of digits in the largest record. Space Complexity: $O(n + \text{base})$.
print("\n--- 4. Stable Radix Sort (LSD Approach via Numerical Buckets) ---")

def stable_radix_sort(arr):
    if not arr:
        return arr

    max_val = max(arr)
    exponent = 1  # Signifies current digit place value (1s, 10s, 100s, etc.)

    # Iterate until processing exceeds the digit size of the maximum element
    while max_val // exponent > 0:
        # Create 10 traditional buckets (0-9 decimal system)
        buckets = [[] for _ in range(10)]

        # Distribute items based on the active digit value
        for num in arr:
            digit_bucket_index = (num // exponent) % 10
            buckets[digit_bucket_index].append(num)

        # Flatten buckets back into the master array (preserves stable FIFO order)
        write_idx = 0
        for bucket in buckets:
            for num in bucket:
                arr[write_idx] = num
                write_idx += 1

        exponent *= 10  # Advance to the next significant decimal column
    return arr

radix_target = [170, 45, 75, 90, 802, 24, 2, 66]
print(f"[Radix Sort Output] Sorted Array: {stable_radix_sort(radix_target)}")
