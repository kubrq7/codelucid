1. Dynamic Arrays & Search Optimization

Academic Overview:

  • Dynamic Array: Python lists are implemented as dynamic arrays. When the list fills up, Python automatically allocates a larger contiguous memory block and copies the elements over.
  • Linear Search: Scanning elements one by one sequentially down the line. Time Complexity is $O(n)$.
print("--- 1. Dynamic Arrays & Linear Search Optimization ---")

# Using built-in Python list methods
numbers_array = [9, 12, 7, 4, 11]
numbers_array.append(8)   # Amortized Time Complexity: O(1)
numbers_array.sort()      # Uses Timsort Algorithm: O(n log n)
print(f"[Built-in Method] Sorted List: {numbers_array}")

# Custom Algorithm: Finding the minimum value (Time Complexity: O(n))
def find_minimum_value(target_list):
    if not target_list:
        raise ValueError("Error: Cannot find the minimum value of an empty list!")
    
    current_min = target_list[0]
    for num in target_list:
        if num < current_min:
            current_min = num
    return current_min

my_array = [7, 12, 9, 4, 11, 8]
print(f"[Custom Algorithm] Lowest value found: {find_minimum_value(my_array)}")

2. Stacks (LIFO Principle)

Academic Overview:

  • Concept: LIFO (Last In First Out). Insertion and deletion operations occur explicitly only at the designated 'Top' element interface.
  • Complexity: Push, Pop, and Peek operations all natively guarantee $O(1)$ time complexity structures.
print("\n--- 2. Class-Based Stack Architecture ---")

class Stack:
    def __init__(self):
        self.storage = []  # Using a standard internal list for stack storage

    def push(self, element):
        """Adds a new element to the top of the stack."""
        self.storage.append(element)

    def pop(self):
        """Removes and returns the top element of the stack."""
        if self.is_empty():
            return "Error: Stack Underflow! The stack is empty."
        return self.storage.pop()

    def peek(self):
        """Returns the top element without removing it."""
        if self.is_empty():
            return "Error: The stack is empty. No element to peek."
        return self.storage[-1]

    def is_empty(self):
        """Checks if the stack contains no elements."""
        return len(self.storage) == 0

    def get_size(self):
        """Returns the current number of elements inside the stack."""
        return len(self.storage)

# Implementation Test
text_editor_history = Stack()
text_editor_history.push("State 1: Initial text typed.")
text_editor_history.push("State 2: Function definition added.")
text_editor_history.push("State 3: Syntactical bug fixed.")

print(f"Current Stack Size: {text_editor_history.get_size()}")
print(f"Top Element (Peek): {text_editor_history.peek()}")
print(f"Undo Triggered (Pop): {text_editor_history.pop()}")
print(f"New Top Element After Pop: {text_editor_history.peek()}")

3. Queues (FIFO Principle)

Academic Overview:

  • Concept: FIFO (First In First Out). Element insertion takes place at the 'Rear', whereas element deletion is performed at the 'Front'.
  • Optimal Solution: Utilizing a raw Python list means front extraction shifts all items, resulting in a costly $O(n)$ footprint. Integrating collections.deque cleanly ensures perfect $O(1)$ time complexity for front removal (popleft).
print("\n--- 3. Optimized Queue Architecture via collections.deque ---")

class Queue:
    def __init__(self):
        self.storage = deque()  # Double-ended queue integration for O(1) performance

    def enqueue(self, element):
        """Appends a new element to the rear of the queue."""
        self.storage.append(element)

    def dequeue(self):
        """Removes and returns the front element of the queue in O(1) time."""
        if self.is_empty():
            return "Error: Queue Underflow! The queue is empty."
        return self.storage.popleft()

    def is_empty(self):
        return len(self.storage) == 0

    def get_size(self):
        return len(self.storage)

# Implementation Test
network_printer = Queue()
network_printer.enqueue("Financial_Report.pdf")
network_printer.enqueue("Architecture_Diagram.png")
network_printer.enqueue("Employment_Contract.docx")

print(f"Documents waiting in printer queue: {network_printer.get_size()}")
print(f"Printing and removing from queue: {network_printer.dequeue()}")
print(f"Remaining documents in queue: {network_printer.get_size()}")

4. Linked Lists & Memory Management

Academic Overview:

  • Concept: A non-contiguous linear structure where elements (Nodes) are explicitly linked using memory pointers.
  • Advantages: Dynamic storage allocation. Inserting or deleting pointer links achieves high $O(1)$ algorithmic efficiency.
  • Disadvantages: No random access (indexing capabilities). Sequential element traversal requires an $O(n)$ lookup path.
print("\n--- 4. Singly Linked List Implementation and Pointer Modification ---")

class LinkedListNode:
    def __init__(self, data):
        self.data = data
        self.next = None

class SinglyLinkedList:
    def __init__(self):
        self.head = None

    def traverse_and_print(self):
        """Traverses the list sequentially and displays the node values."""
        current_node = self.head
        while current_node:
            print(current_node.data, end=" -> ")
            current_node = current_node.next
        print("Null")

    def insert_at_position(self, data, position):
        """Inserts a new node at a specific position safely."""
        new_node = LinkedListNode(data)
        
        if position == 1:
            new_node.next = self.head
            self.head = new_node
            return

        current_node = self.head
        for _ in range(position - 2):
            if current_node is None or current_node.next is None:
                break
            current_node = current_node.next

        if current_node is not None:
            new_node.next = current_node.next
            current_node.next = new_node

    def delete_node_by_value(self, target_value):
        """Disconnects a node containing the target value from the memory chain."""
        current_node = self.head

        if current_node and current_node.data == target_value:
            self.head = current_node.next
            return

        while current_node and current_node.next and current_node.next.data != target_value:
            current_node = current_node.next

        if current_node and current_node.next is not None:
            current_node.next = current_node.next.next

# Implementation Test
linked_list = SinglyLinkedList()
linked_list.head = LinkedListNode(7)
second_node = LinkedListNode(11)
third_node = LinkedListNode(3)

linked_list.head.next = second_node
second_node.next = third_node

print("Original Linked List Chain:")
linked_list.traverse_and_print()

print("\nInserting value 97 at Position 2...")
linked_list.insert_at_position(97, 2)
linked_list.traverse_and_print()

print("\nDeleting value 11 from the Linked List...")
linked_list.delete_node_by_value(11)
linked_list.traverse_and_print()

print("\n[SUCCESS] Linear Data Structures script executed perfectly with zero errors.")
