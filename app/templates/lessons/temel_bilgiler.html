01. Python Indentation Rules, Output Methods, and Basic Variables

1. Python Indentation (The Most Important Rule)

In other languages, indentation is just for readability. In Python, it is MANDATORY. Python uses indentation to define and indicate a block of code.

  • The standard is 4 spaces (or 1 Tab).
  • It must be at least 1 space, and you MUST use the same amount within the same block.
if 5 > 2:
    print("Five is greater than two!")  # Shifted right by 4 spaces

if 5 > 2:
    print("Line 1 of the block")
    print("Line 2 of the block")  # Matches the indentation above
Strict Rule: Incorrect indentation will directly raise an IndentationError or SyntaxError.

2. Python Variables (Quick Introduction)

A variable is automatically created the moment you assign a value to it using the single equals sign (=).

x = 5
y = "Hello, World!"
print(x, y)  # Displays the values stored inside x and y

3. Advanced print() Methods & Outputs

A) Using the `end` Parameter

By default, print() automatically jumps to a new line at the end. You can change this behavior using end=" " to print things on the same line:

print("Hello", end=" ")
print("World!")  # Output: Hello World!

B) Numbers vs Text in Print

Unlike text/strings, we do NOT enclose numbers or mathematical operations in quotation marks to perform calculation directly inside print:

print(300)
print(5 * 2)  # Output: 10

C) Combining Text and Numbers

You must separate different data types using commas (,) inside print(). Python automatically puts a space character where the comma is:

print("I am", 20, "years old")

D) Writing Multiple Statements on a Single Line

Although writing code line-by-line is preferred, you can use a semicolon (;) to separate and execute multiple statements on a single line:

print("Hello!"); print("Hey!")

4. Code Comments in Python

Comments are used to explain Python code and make it readable. Comments begin with a hash sign (#), and Python will ignore them. Triple quotes (""") are used for multi-line notes.
