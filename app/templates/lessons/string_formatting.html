20. Comprehensive Guide to Modern F-Strings and Legacy String Formatting

1. Modern F-Strings (Python 3.6+)

Prefixing strings with 'f' or 'F' opens direct evaluation expressions inside curly braces {}.

price = 59
tax_rate = 0.25
fruit = "apples"

# A) Raw Variables & Mathematical Computations Directly Inside Placeholders
basic_invoice = f"The standard unit price is {price} dollars."
calculated_invoice = f"Total with taxes applied: {price + (price * tax_rate)} dollars."
print("--- F-String Calculations ---")
print(basic_invoice)
print(calculated_invoice)

# B) Executing Inline Conditionals (Ternary Operators)
# Syntax: {true_value if condition else false_value}
pricing_evaluation = f"Target product stock is {'Expensive' if price > 50 else 'Cheap'}."
print(pricing_evaluation)

# C) Function & Method Invocations
print(f"Formatted Product Title: {fruit.upper()}")

def feet_to_meters_converter(feet_value):
    return feet_value * 0.3048

flight_alt_log = f"The plane status tracking altitude: {feet_to_meters_converter(30000):.2f} meters."
print(flight_alt_log)

2. Formatting Specifiers & Modifiers

Modifiers are added after a colon symbol (:) inside placeholders to control text rendering.

large_currency = 5900000.768

# :.2f -> Renders a float fixed-point number rounded strictly to 2 decimal places
print(f"Fixed decimal representation: {large_currency:.2f}")

# :, -> Adds a standard comma symbol as a thousands separation marker
print(f"Thousands comma format: {large_currency:,}")

# Combined Modifier: Commas for thousands and rounded to 2 decimal places
print(f"Fully sanitized ledger value: {large_currency:,.2f}")

# --- Common Structural Modifiers ---
# :b  -> Binary formatting translation representation
# :x  -> Lowercase Hexadecimal representation conversion
# :%  -> Automatic percentage conversion scaling (multiplies by 100 and appends %)
integer_value = 42
percentage_ratio = 0.756
print(f"Decimal {integer_value} in Binary layout: {integer_value:b}")
print(f"Decimal {integer_value} in Hex layout: {integer_value:x}")
print(f"Ratio turned to percentage string: {percentage_ratio:.1%}")

3. The Legacy .format() Syntax Protocols

Used primarily prior to Python 3.6, the .format() engine uses distinct positional modes.

quantity, item_id, cost = 3, 567, 49.95

# A) Blank Positional Mapping (Passed sequentially left to right)
order_template_alpha = "Order Intent: Buy {} units of item #{} for {} dollars."
print(order_template_alpha.format(quantity, item_id, cost))

# B) Explicit Index Mapping (Allows out-of-order calls and duplicate re-use)
# Index 0 -> age | Index 1 -> name
age, name = 36, "John"
reused_index_string = "Identity Record: His name is {1}. {1} is {0} years old."
print(reused_index_string.format(age, name))

# C) Named Keyword Parameter Mapping (Highly descriptive key-value tracking)
custom_car_profile = "Inventory Match: Brand is {brand_name}, Model variant: {model_code}."
print(custom_car_profile.format(brand_name="Ford", model_code="Mustang"))
