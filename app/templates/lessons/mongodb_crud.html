01. Python Backend Unit - MongoDB (NoSQL)

A comprehensive master guide to working with MongoDB in a Python backend ecosystem using the official pymongo library standard to implement complete CRUD architectures.

import pymongo

1. MongoDB Initialization & Collection Setup

Academic Overview:

  • NoSQL Core Structure: MongoDB stores data in flexible, JSON-like documents rather than traditional relational tables.
  • Mapping Paradigms: A SQL Database maps directly to a NoSQL Database, a SQL Table equates to a MongoDB Collection, and a SQL Row is stored as a BSON (Binary JSON) Document.
print("--- Section 1: Database and Collection Setup ---")

# Establish connection to the local MongoDB instance (Default port: 27017)
client = pymongo.MongoClient("mongodb://localhost:27017/")

# Initialize the target database container
target_db = client["production_database"]

# Initialize the target collection (Equivalent to a SQL table)
product_collection = target_db["products"]
print("[INFO] MongoDB client connected and 'products' collection initialized.\n")

2. Data Insertion Mechanics (Create)

Academic Overview:

  • Insert One: Adds a single Python dictionary mapped directly to BSON into the cluster collection. If no explicit _id is given, MongoDB assigns a unique 12-byte ObjectId automatically.
  • Insert Many: Passes an iterable array list of records via a single atomic network request, radically minimizing network latency and overhead.
print("--- Section 2: Document Insertion Operations ---")

# Inserting a single document (Python dictionary structure mapping to BSON)
single_product = { "name": "Wireless Headphones", "price": 1200, "category": "Electronics", "stock": 45 }
insert_result = product_collection.insert_one(single_product)
print(f"[Insert] Single document inserted with ID: {insert_result.inserted_id}")

# Inserting multiple documents simultaneously (Optimized bulk insertion)
bulk_products = [
    { "name": "Mechanical Keyboard", "price": 2500, "category": "Electronics", "stock": 15 },
    { "name": "Gaming Mouse", "price": 850, "category": "Electronics", "stock": 60 },
    { "name": "Smart Watch", "price": 3400, "category": "Wearables", "stock": 20 },
    { "name": "Ergonomic Chair", "price": 4500, "category": "Furniture", "stock": 5 }
]
bulk_result = product_collection.insert_many(bulk_products)
print(f"[Insert] Bulk insertion completed. Total count: {len(bulk_result.inserted_ids)}\n")

3. Document Retrieval, Querying & Limiting (Read)

Academic Overview:

  • Find One: Resolves and yields the first matching physical document from the target sequence structure.
  • Query Operators: Evaluation keys handle advanced condition filtering without writing raw code strings. Common operations include:
    • $gt: Greater Than ($>$)
    • $gte: Greater Than or Equal To ($\ge$)
    • $lt: Less Than ($<$)
    • $lte: Less Than or Equal To ($\le$)
  • Cursor Modification: Methods like .limit() don't slice datasets locally; they restrict records directly inside the database cluster to protect system memory.
print("--- Section 3: Advanced Querying and Result Limiting ---")

# 1. Fetching the first available document in the collection
first_item = product_collection.find_one()
print(f"[Find One] Initial Document: {first_item['name'] if first_item else 'None'}")

# 2. Querying with evaluation operators ($gt = Greater Than)
price_query = { "price": { "$gt": 1500 } }
filtered_items = product_collection.find(price_query)

print("[Query Result] Products with price greater than 1500:")
for item in filtered_items:
    print(f" - {item['name']}: {item['price']} TRY")

# 3. Restricting result set volume using the Limit clause
limited_items = product_collection.find().limit(2)
print("[Limit Result] Restricted Output (Top 2 Items):")
for item in limited_items:
    print(f" - {item['name']}")
print("")

4. Data Sorting Mechanics

Academic Overview:

  • Ordering: The .sort() method accepts directional integer metrics to order your documents. Using a 1 enforces Ascending order, whereas a -1 enforces Descending order.
print("--- Section 4: Document Sorting Operations ---")

# Sorting order definition: Ascending (1) or Descending (-1)
# Sorting products from highest price to lowest price
sorted_by_price = product_collection.find().sort("price", -1)

print("[Sort Result] Price Evaluation (Descending):")
for item in sorted_by_price:
    print(f" - {item['name']}: {item['price']} TRY")
print("")

5. Document Modification (Update)

Academic Overview:

  • Atomic Operators: Modifications require explicit updates to prevent accidentally overwriting the entire document.
    • $set: Rewrites specific fields with new values while leaving other keys untouched.
    • $inc: Mathematically adjusts existing numeric values by a positive or negative amount directly in memory.
print("--- Section 5: Document Modification Operations ---")

# Modifying a single document using the atomic $set operator
update_filter = { "name": "Gaming Mouse" }
new_values = { "$set": { "price": 950, "stock": 55 } }
product_collection.update_one(update_filter, new_values)
print("[Update] 'Gaming Mouse' metrics updated successfully.")

# Modifying multiple documents utilizing the arithmetic $inc operator
# Increments stock value by 5 for all records matching the 'Electronics' category
product_collection.update_many({ "category": "Electronics" }, { "$inc": { "stock": 5 } })
print("[Update Many] Stock incremented for all items under 'Electronics' category.\n")

6. Document Deletion & Collection Drop (Delete)

Academic Overview:

  • Delete One / Many: Removes active documents that match targeted query filters from the collection space.
  • Drop: Completely purges the entire collection structural framework and its indices from physical memory, making it much more efficient than executing long individual document deletions.
print("--- Section 6: Deletion and Cleanup Operations ---")

# Removing a specific document from the collection context
delete_query = { "name": "Wireless Headphones" }
product_collection.delete_one(delete_query)
print("[Delete] 'Wireless Headphones' removed from collection.")

# Erasing the entire collection structural framework from the database (Drop)
product_collection.drop()
print("[Drop] 'products' collection completely removed from the database instance.")

print("\n[SUCCESS] All MongoDB CRUD architectural layers executed flawlessly.")
