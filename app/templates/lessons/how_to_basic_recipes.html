1. Remove Duplicates from a List (Preserving Order vs. Performance)

Academic Overview:

  • Hash-Set Deduplication: Instantiating a set() collection drops duplicates in $O(n)$ time by processing indices through internal hashing matrices. However, it strips away sequence index alignment, yielding an unordered array.
  • Dictionary-Key Deduplication: Python 3.7+ guarantees that standard dictionaries strictly maintain insertion order. Harnessing dict.fromkeys() isolates unique collection elements in $O(n)$ time while ensuring order preservation.
print("--- 1. Removing Duplicates Mechanics ---")

raw_list = [5, 2, 9, 2, 5, 1, 3, 9, 7]
print(f"Original List: {raw_list}")

# Approach A: The Set conversion method. 
# Time Complexity: O(N) -> Fast due to hash-set lookups, but does NOT preserve order.
unique_via_set = list(set(raw_list))
print(f"[Optimal for Speed] Unique List (Set): {unique_via_set}")

# Approach B: Dictionary keys method.
# Time Complexity: O(N) -> Fast, and it PRESERVES the original insertion order.
unique_via_dict = list(dict.fromkeys(raw_list))
print(f"[Optimal for Order] Unique List (Dict): {unique_via_dict}\n")

2. Reverse a Sequence (String and List Inversion)

Academic Overview:

  • Extended Slicing: Slicing expressions configured with a step parameter of -1 ([::-1]) leverage highly optimized C-level memory access structures to copy and reverse elements cleanly.
  • Lazy Iteration: The built-in reversed() function performs index lookup queries without allocating an identical duplicate sequence inside memory, returning a lazy iterator that operates in $O(1)$ space.
print("--- 2. Sequence Reversal Mechanics ---")

sample_string = "Engineers Change The World"
sample_array = [10, 20, 30, 40, 50]
print(f"Original String: '{sample_string}'")
print(f"Original Array: {sample_array}")

# Approach A: Extended Slicing [start:stop:step]
reversed_string_slice = sample_string[::-1]
reversed_array_slice = sample_array[::-1]
print(f"[Slicing Method] Reversed String: '{reversed_string_slice}'")
print(f"[Slicing Method] Reversed Array: {reversed_array_slice}")

# Approach B: Built-in reversed() iterator
reversed_string_builtin = "".join(reversed(sample_string))
reversed_array_builtin = list(reversed(sample_array))
print(f"[Built-in Method] Reversed String: '{reversed_string_builtin}'")
print(f"[Built-in Method] Reversed Array: {reversed_array_builtin}\n")
