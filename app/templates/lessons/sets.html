10. Comprehensive Guide to Python Sets & Frozensets (Mathematical Operations)

1. Set Core Definition & Truthy Duplicates

active_ips = {"192.168.1.1", "10.0.0.5", "172.16.0.2", "192.168.1.1"}
print(active_ips) # Duplicates are automatically ignored!

# ⚠️ THE BOOLEAN-INTEGER OVERLAP TRAP
boolean_clash_1 = {"production", True, 1, 55} # 1 is discarded!
empty_structure = set() # Required for empty set

2. Accessing Items & Membership Speed

Sets are unindexed. You cannot read them using index brackets like set[0].

monitored_services = {"Nginx", "Docker", "Redis", "Postgres"}
print("Docker" in monitored_services) # O(1) time complexity (lightning fast)

3. Modification Methods (Add, Discard, Pop)

admin_scopes = {"read", "write"}
admin_scopes.add("execute")
admin_scopes.discard("ghost_role") # Safe; no crash if missing
popped_element = admin_scopes.pop() # Arbitrary element

4. Mathematical Set Manipulations

Supports Union (|), Intersection (&), Difference (-), and Symmetric Difference (^).

backend_devs = {"Alice", "Bob", "Charlie"}
cloud_devs = {"Charlie", "David", "Elena"}
shared_devs_symbol = backend_devs & cloud_devs # {'Charlie'}

5. In-place Mutation Updates

prod_packages.intersection_update(dev_packages)

6. Relational Set Checks (Subsets)

required_permissions = {"read", "write"}
print(required_permissions.issubset(user_permissions))

7. The Immutable Frozenset

A set that has been permanently write-protected. Modification commands are disabled.

immutable_rules = frozenset({"strict_mode", "allow_cookies", "use_ssl"})
