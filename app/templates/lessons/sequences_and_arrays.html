15. Unified Guide to Range Sequences and Mutable Array Structures

1. The Immutable Range Sequence Object

The range() constructor returns an immutable sequence object of type 'range'. It is calculated lazily, making it highly memory-efficient for loops.
Formula: range(start, stop, step)

# Single Argument: Evaluates as the exclusive 'stop' parameter. Default 'start' is 0.
zero_to_nine = range(10)
print(f"Type: {type(zero_to_nine)} | Sequence: {zero_to_nine}")

# Two Arguments: Evaluates as (start, exclusive_stop)
three_to_nine = range(3, 10)

# Three Arguments: Evaluates as (start, exclusive_stop, step_increment)
odd_three_to_nine = range(3, 10, 2)

# --- Converting Range Sequences to Materialized Lists ---
print(list(range(5)))          # Outputs: [0, 1, 2, 3, 4]
print(list(range(1, 6)))       # Outputs: [1, 2, 3, 4, 5]
print(list(range(5, 20, 3)))   # Outputs: [5, 8, 11, 14, 17]

# --- Range Operations: Slicing & Membership ---
numeric_sequence = range(0, 10, 2) # Generates values: 0, 2, 4, 6, 8

print(f"Value at index 2: {numeric_sequence[2]}")  # Returns concrete value: 4
print(f"Sliced sub-range: {numeric_sequence[:3]}") # Returns a new range object: range(0, 6, 2)

# O(1) Constant-Time Membership Testing via 'in'
print(6 in numeric_sequence) # Returns True
print(7 in numeric_sequence) # Returns False
print(f"Total elements: {len(numeric_sequence)}") # Outputs: 5

2. Lists Deployed as Mutable Arrays

Python does not possess a native primitive 'array' type. Instead, built-in lists are scaled to perform as mutable tracking arrays for single data types.

cars = ["Ford", "Volvo", "BMW"]

# Accessing and mutating elements by explicit index position
print(f"Initial Index 0: {cars[0]}")
cars[0] = "Toyota"
print(f"Updated Index 0: {cars[0]}")

# Appending new data packets to the tail end of the sequence
cars.append("Honda")
print(f"After Append: {cars}")

# Popping items out of memory by explicit index tracking
removed_car = cars.pop(1) # Extracted index 1 ("Volvo") out of the array
print(f"Popped Element: {removed_car} | Current Array: {cars}")

# Explicit value removal (Deletes ONLY the first matching instance encountered)
cars.remove("BMW")
print(f"After Explicit Value Removal: {cars}")

# --- Iterating Over Array Elements ---
for car in cars:
    print(f"Processing Car: {car}")
