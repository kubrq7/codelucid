05. Deep Dive into Python Strings, Slicing, Methods, and F-Strings

⚠️ GOLDEN RULE: STRINGS ARE IMMUTABLE!
All string methods return NEW values. They DO NOT modify the original string! To change a string permanently, you must assign it back to the variable.

Example:
txt = "hello"
txt = txt.upper() # Now it is permanently changed!

1. Strings are Arrays (Indexing & Loops)

Python does not have a separate "character" data type. Strings are ordered sequences of Unicode characters. Indexing starts at 0.

a = "Hello, World!"
print(a[0])  # Returns: H
print(a[4])  # Returns: o
print(len(a)) # Returns: 13

for character in "cherry":
    print(character)

2. String Slicing (Substring Extraction)

Syntax: string[start_index : end_index]. CRITICAL: Python includes the 'start' index but EXCLUDES the 'end' index!

b = "Hello, World!"
print(b[2:8])   # Returns: "llo, W"
print(b[:5])    # Returns: "Hello"
print(b[2:])    # Returns: "llo, World!"
print(b[-5:-2]) # Returns: "orl"

3. Membership Operators

Used to check if a specific phrase or character exists inside a text using in or not in.

txt = "The best things in life are free!"
print("free" in txt)      # Output: True
print("expensive" not in txt) # Output: True

4. Most Common String Methods

sample = "  Hello, World!  "
print(sample.upper())       # "  HELLO, WORLD!  "
print(sample.strip())       # "Hello, World!"
print(sample.replace("H", "J")) # "  Jello, World!  "
print(sample.split(","))    # ['  Hello', ' World!  ']

5. String Concatenation & F-Strings

age = 19
intro = f"My name is Kubra, I am {age} years old."
price = 59
formatted_price = f"The price is {price:.2f} dollars" # "The price is 59.00 dollars"
print(f"Math: {20 * 59}") # 1180

6. Escape Characters

Used to insert characters that are otherwise illegal in a string.

viking_text = "We are the so-called \"Vikings\" from the north."
# \" : Double Quote, \n : New Line, \t : Tab, \\ : Backslash
