17. Standard Libraries Quiz Question 1 of 9

01. Date & Time

Which module is used to work with dates and times in Python?

Reason

The datetime module contains the most robust set of classes for date/time manipulation.

02. Datetime Attribute

What does the following code return? today = datetime.datetime.now() print(today.year)

Reason

The .year attribute extracts the integer year value from the datetime object.

03. Formatting

Which method converts a datetime object into a formatted string?

Reason

strftime (String Format Time) turns datetime objects into human-readable strings.

04. Math Operations

Which function returns the square root of a number?

Reason

math.sqrt() is the standard way to calculate square roots in Python's math library.

05. Ceil Method

What is the output of: print(math.ceil(4.2))?

Reason

math.ceil() rounds any decimal value up to the next integer.

06. JSON String to Dict

Which function converts a JSON string into a Python dictionary?

Reason

json.loads (Load String) is used to deserialize JSON strings.

07. Object to JSON

Which function converts a Python object into a JSON-formatted string?

Reason

json.dumps (Dump String) serializes Python objects to JSON strings.

08. JSON Indent

What is the purpose of the indent parameter in json.dumps()?

Reason

indent adds pretty-printing (newlines and spacing) to the output.

09. Bonus: Pi

Which constant represents the mathematical value π (pi)?

Reason

math.pi is the standard IEEE 754 approximation of π.
