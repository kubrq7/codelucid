11. Dictionaries Quiz Question 1 of 9

01. Dict Basics

Which statement about Python dictionaries is TRUE?

Reason

Dictionaries store unique key-value pairs; keys can be any immutable type, not just strings.

02. Unique Keys

What will be printed? person = {"name": "Kubra", "name": "Alice"} print(person["name"])

Reason

Keys must be unique; a duplicate key definition overwrites the previous value.

03. Safe Retrieval

Which method safely retrieves a value without raising an error if the key does not exist?

Reason

get() returns None instead of raising a KeyError if the key is missing.

04. Missing Key

What will be printed? student = {"name": "John", "age": 20} print(student.get("grade"))

Reason

If the key is not in the dictionary, get() returns None by default.

05. Items Method

Which method returns both keys and values together?

Reason

items() provides view objects containing (key, value) tuples.

06. Updating Values

What will be printed? car = {"brand": "Tesla", "year": 2025} car.update({"year": 2026}) print(car["year"])

Reason

update() adds new keys or updates the values of existing keys.

07. Pop Method

What will be printed? config = {"host": "localhost", "port": 5000} config.pop("host") print(config)

Reason

pop(key) removes the key-value pair and modifies the dictionary in-place.

08. Reference Assignment

What will be printed? a = {"x": 1} b = a b["x"] = 99 print(a["x"])

Reason

b = a creates a reference; both variables point to the same object in memory.

09. Bonus: Nested Dictionaries

What will be printed? network = {"server": {"ip": "192.168.1.10"}} print(network["server"]["ip"])

Reason

Chain multiple keys in brackets to navigate into nested structures.
