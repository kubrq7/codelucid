08. Lists Quiz Question 1 of 10

01. List Basics

Which statement about Python lists is TRUE?

Reason

Lists are ordered, mutable, and can store duplicate values as well as different data types.

02. Negative Indexing

What will be printed? tools = ["VS_Code", "Git", "Docker", "Terminal"] print(tools[-2])

Reason

Negative indexing starts from the end; -1 is the last item, so -2 is "Docker".

03. List Slicing

What is the output? items = ["A", "B", "C", "D", "E"] print(items[1:4])

Reason

List slicing [1:4] includes the start index (1) but excludes the end index (4).

04. Appending

What will be the final list? numbers = [10, 20, 30] numbers.append(40) print(numbers)

Reason

append() always adds a new item to the end of the list.

05. Inserting

What will be printed? letters = ["A", "B", "C"] letters.insert(1, "X") print(letters)

Reason

insert(1, "X") inserts the element before index 1.

06. Sorting

What will be printed? nums = [3, 1, 2] nums.sort() print(nums)

Reason

sort() rearranges the original list in ascending order.

07. Reference Logic

What will be printed? a = [1, 2, 3] b = a b.append(4) print(a)

Reason

b = a does not copy; both point to the same memory object.

08. Copying Lists

Which statement creates a new independent copy of a list?

Reason

copy() creates a new list with the same elements.

09. List Comprehension

Which list comprehension keeps only numbers greater than 50?

Reason

Syntax: [expression for item in iterable if condition].

10. Case-Sensitive Sorting

What will be printed? names = ["Bob", "alice", "Charlie"] names.sort() print(names)

Reason

By default, sort() is case-sensitive: uppercase letters (ASCII) come before lowercase.
