02. Variables Quiz Question 1 of 10

01. Code Execution Flow

In what order does Python execute statements in a program?

Reason

Python executes statements sequentially from the first line to the last unless control structures (such as loops or conditions) change the flow.

02. Statement Outputs

What is the output of the following code? print("First") print("Second") print("Third")

Reason

Python executes each statement in the exact order it appears.

03. Dynamic Typing

What is dynamic typing in Python?

Reason

Python variables are dynamically typed, meaning the same variable can store different types of values at different times.

04. Variable Reassignment

What is the final data type of x? x = 4 x = "Sally"

Reason

The second assignment replaces the previous value. The latest assignment determines the variable's current type.

05. Data Casting

Which function converts a value into a floating-point number?

Reason

The float() function converts compatible values into floating-point numbers.

06. The Type Function

What is the output of the following statement? print(type(5))

Reason

The type() function returns the exact data type of the object.

07. Naming Conventions

Which statement about variable names is correct?

Reason

Python is case-sensitive. Changing the capitalization creates a completely different variable.

08. Multiple Assignments

Which statement correctly assigns one value to three variables?

Reason

Using chained assignment stores the same value in multiple variables.

09. Variable Scope

Where is a local variable accessible?

Reason

A local variable exists only within the function where it is defined.

10. Operations & Errors
