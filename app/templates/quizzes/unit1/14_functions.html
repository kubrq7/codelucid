14. Functions Quiz Question 1 of 11

01. Function Purpose

What is the main purpose of a function in Python?

Reason

Functions promote code reuse and modularity by grouping logic together.

02. Param vs Argument

What is the difference between a parameter and an argument?

Reason

Parameters are placeholders (definition), Arguments are the real data (call).

03. Return Values

What will be printed? def greet(name): return f"Hello {name}" print(greet("Kubra"))

Reason

The function returns the formatted string based on the input argument.

04. *args

What data type does *args collect its values into?

Reason

*args is used to pack arbitrary positional arguments into a tuple.

05. **kwargs

What data type does **kwargs collect its values into?

Reason

**kwargs collects arbitrary keyword arguments into a dictionary.

06. Argument Unpacking

What will be printed? def multiply(a, b): return a * b values = [3, 4] print(multiply(*values))

Reason

The * operator unpacks the list elements as individual function arguments.

07. Recursion

Which statement about recursion is TRUE?

Reason

Without a base case, recursion leads to infinite calls and a StackOverflow.

08. Lambda Functions

What is the purpose of a lambda function?

Reason

Lambdas are small, anonymous functions defined in a single line.

09. Decorators

Which statement about decorators is TRUE?

Reason

Decorators act as wrappers around functions to augment their functionality.

10. Scope (Nonlocal)

Which keyword allows a nested function to modify a variable defined in its enclosing function?

Reason

nonlocal allows access to the parent function's scope, not the global scope.

11. Bonus: Global

Which keyword allows a function to modify a variable defined at the module (global) level?

Reason

The 'global' keyword explicitly links the variable inside the function to the module-level scope.
