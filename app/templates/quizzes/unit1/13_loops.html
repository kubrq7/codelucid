01. Match-Case

Reason

02. Match Logic

What will be printed? status = 404 match status: case 200: print("OK") case 404: print("Not Found") case _: print("Unknown")

Reason

The code matches 404 and executes the corresponding block.

03. While Loops

Which statement about a while loop is TRUE?

Reason

While loops are condition-controlled, running as long as the expression is True.

04. Break Statement

What is the main purpose of the break statement?

Reason

break completely terminates the innermost loop.

05. Continue Statement

What is the main purpose of the continue statement?

Reason

continue abandons the remaining code in the loop body and jumps to the next iteration.

06. For-Else Structure

What will be printed? for i in range(1, 6): if i == 3: break else: print("Finished") print("Done")

Reason

The 'else' block runs only if the loop completes without 'break'.

07. Range Function

What values are produced by range(2, 8, 2)?

Reason

The stop value 8 is exclusive; it counts by 2 starting from 2.

08. Nested Loops

How many times will "Hi" be printed? for i in range(2): for j in range(3): print("Hi")

Reason

Total iterations = outer (2) × inner (3) = 6.

09. Pass Statement

What is the purpose of the pass statement inside a loop?

Reason

pass is a syntactic null-operation, often used as a placeholder during development.

10. Bonus: Continue

What will be printed? for i in range(3): if i == 1: continue print(i)

Reason

When i=1, the loop hits 'continue', skipping print for that iteration.
