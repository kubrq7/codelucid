1. WHAT IS PYTHON? WHY AND WHERE IS IT USED?

Python is a high-level, interpreted programming language known for its readability and simplicity.
WHY PYTHON?
• It has a clean syntax; it does not use complex rules or curly braces for code blocks.
• It has one of the largest communities in the world, making it very easy to find resources.
WHERE IS IT USED?
• Artificial Intelligence & Data Science (Machine Learning, Deep Learning)
• Web Development (Backend management using frameworks like Django and Flask)
• Game Development (Basic and 2D games with libraries like Pygame)
• Cyber Security & Automation (Writing scripts to automate repetitive tasks)
2. ESSENTIAL SYMBOLS AND THEIR MEANINGS

[ Curly Braces { } ]
In other languages (C++, Java, C#): Used to define the boundaries of code blocks.
In Python: NEVER used for code blocks (Python uses indentation instead). It is only used for Dictionaries, Sets, or string formatting (f-strings). Example: my_dict = {"name": "Kubra", "age": 19}

[ Colon : ]
It signals the start of a code block (a condition, a loop, or a function). The lines following a colon must always be INDENTED (shifted to the right). Example: if x > 5:

[ Hash / Pound Sign # ]
Used to write comments. Python ignores lines starting with this symbol.

[ Equals Signs (= vs ==) ]
Single Equals (=): Used for assignment (putting a value inside a variable).
Double Equals (==): Used for comparison (checks if two values are equal).

[ Parentheses ( ) ]
Used to call/execute functions (like print(), input()) or for math priority.

[ Square Brackets [ ] ]
Used to create Lists to store multiple items in a specific order. Example: languages = ["Python", "HTML", "CSS"]

4. PYTHON INSTALL AND QUICKSTART
If Python is not installed on your computer, you can download it for free from the official website: https://www.python.org/
Python is an interpreted programming language; this means that as a developer you write Python (.py) files in a text editor and then put those files into the python interpreter to be executed. Let's write our first Python file, called hello.py:
# hello.py: print("Hello, World!")
Save your file. Open your command line, navigate to the directory where you saved your file, and run: The output should be: Hello, World! Congratulations, you have written and executed your first Python program.
6. CHECKING PYTHON VERSION & HOW IT WORKS
- sys.version: A built-in variable that holds your Python version info.
- print(): The tool used to display any data or text on the terminal screen.
- Together: print(sys.version) fetches the version info and displays it.
import sys #Imported at the top according to professional standards (PEP 8) print(sys.version)

💡 CURIOUS NOTE

When you run the code above, you will see a date in the terminal (e.g., Jun 7 2023).
Q: Why does it show a past date (like 2023) even though not this time?
A: That date has nothing to do with today's date or your computer's clock! It is the official "Release/Production Date" of that specific Python version. It tells you exactly when the Python team packaged and released this version to the world.
